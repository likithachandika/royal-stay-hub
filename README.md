# 👑 Royal Residency & Suites - Hotel Booking Prototype

A responsive, client-side web application prototype for searching and reserving luxury hotel rooms across major states and districts in India. Built with clean HTML5, CSS3, and modern JavaScript (ES6).

---

## ✨ Features

- **Dynamic Location Filtering:** Select Indian states (Telangana, Andhra Pradesh, Karnataka, Maharashtra, Tamil Nadu, Delhi, Kerala) to dynamically populate corresponding districts and cities.
- **Multi-criteria Search:** Filter available rooms by State, District/City, Guest Capacity, and Room Category (Standard, Deluxe, Executive Suite, Presidential Suite).
- **Interactive Booking Modal:** Popup modal displaying full room details along with real customer reviews and star ratings.
- **Form Validation:** Client-side validation ensuring valid Full Name, 10-digit Mobile Number, Email Address, and Identification input prior to confirmation.
- **Responsive & Modern UI:** Designed using CSS Grid, Flexbox, smooth hover animations, and modern typography.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Grid & Flexbox)
- **Scripting:** JavaScript (Vanilla ES6 / DOM Manipulation)
- **Styling:** Custom CSS with modern card & modal UI components
