# 👑 Royal Stay Hub

> **Experience World-Class Luxury** — A handpicked premium hotel, resort, and suite booking platform covering all 28 states of India.

---

## 🌟 Overview

**Royal Stay Hub** is a modern, feature-rich responsive web application designed for luxury travelers, corporate executives, and tourists. It provides seamless searching, filtering, and booking across multiple destination categories (Cities, Mountains, Pilgrims, and Beaches) with integrated loyalty programs, FAQs, support contacts, and interactive user authentication modals.

---

## ✨ Key Features

- **📍 Nationwide Coverage & City Navigation:** Quick-filter dropdowns and interactive state/district selectors covering all 28 Indian states and major business/tourist hubs (Hyderabad, Mumbai, Delhi, Bengaluru, Goa, etc.).
- **🎛️ Advanced Search Engine:** Filter properties dynamically by **State**, **District/City**, **Guest Count**, and **Room Category** (ranging from *Economy Standard Room* to *Royal Heritage Villa with Private Pool*).
- **🗂️ Categorized Discover Grid:** Tabbed discovery system for Popular Cities, Mountains, Pilgrims, and Beaches.
- **🏷️ Multi-Tier Room Categories:** Supports 5 distinct room tiers:
  1. Economy Standard Room
  2. Deluxe Comfort Suite
  3. Executive Business Suite
  4. Presidential Penthouse
  5. Royal Heritage Villa (Private Pool)
- **👑 Royal Crown VIP Membership:** Loyalty program banner detailing instant discounts, priority 24/7 concierge support, and complimentary stay perks.
- **📰 In The News Section:** Highlights recent media coverage and corporate milestone updates.
- **📱 Mobile App Promotion:** Banner featuring app store links and QR code preview.
- **❓ Interactive Travel Guide & FAQs:** Accordion-style expandable panels for destination guides and frequently asked questions.
- **💬 Direct Support & Modals:** Sticky header support numbers, login/signup modals, and interactive user flows.

---

## 🛠️ Tech Stack

- **Markup & Structure:** HTML5 (Semantic elements, responsive layout grids)
- **Styling:** CSS3 (Custom properties / CSS Variables, Flexbox, CSS Grid, Responsive Media Queries)
- **Icons & Fonts:** Font Awesome 6.4.0 (`fa-solid`, `fa-brands`), Google Fonts (*Poppins*, *Segoe UI*)
- **Interactivity:** Vanilla JavaScript (DOM manipulation, dynamic filtering, modal toggles, image sliders)
